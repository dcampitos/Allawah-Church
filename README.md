# Allawah Community Church website

Static website — no build step needed.

- `index.html` — homepage
- `events.html` — full events page
- `images/` — all photos (keep this folder next to the HTML files)

## Publish with GitHub Pages
1. Upload `index.html`, `events.html`, `README.md` and the whole `images` folder to the root of your repository.
2. In the repo go to **Settings → Pages**, set **Source** to "Deploy from a branch", choose `main` and `/ (root)`, then **Save**.
3. After a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.

## Notes
- The contact form opens the visitor's email app addressed to info@allawahchurch.com (GitHub Pages can't send email itself). A form service such as Formspree can be added later.
- Event dates are samples from the old site's calendar — update them in both HTML files.
- The "Child Safe Policy" footer link still needs its page or URL.
